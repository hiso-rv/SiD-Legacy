# ✦ About SiD Legacy

**SiD Legacy** is an unofficial preservation and reconstruction project dedicated to bringing the experience of **SiD Story / SiD Classic** back to life.

SiD was more than a collection of characters and interfaces. Its stories, Sidians, progression systems, battles, environments and distinctive visual identity formed an experience remembered by the community long after the original game became unavailable.

**SiD Legacy exists to preserve that experience.**

The project is gradually reconstructing the game system by system while studying surviving historical material to understand how the original experience behaved.

The objective is not simply to reproduce old screens.

The objective is to restore a **connected, persistent and playable game**.

> ### Same SiD. A living game again.

SiD Legacy is currently under active development and is **not yet available as a public playable build**.

---

# ✦ Project Goals

The original SiD experience remains the primary reference for the project.

SiD Legacy aims to preserve and reconstruct:

- the original visual identity and interface
- Sidians and character progression
- Story and character interactions
- Home and its connected areas
- School and Lessons
- Team Organization
- Exploration
- Battle
- Feed
- Shop and economy systems
- Mission Board
- Fusion
- Skill Up
- Atelier and crafting
- Inventory and rewards
- Summoning
- player progression
- persistent account state
- additional systems recovered from surviving versions of the game

SiD Legacy is not intended to reinterpret SiD as an unrelated modern game.

The goal is to preserve what made the original experience recognizable while rebuilding the systems required for it to function again.

This is an important foundation for SiD Legacy.

# ✦ Historical Preservation & Research

SiD Legacy development is accompanied by preservation research into surviving historical SiD material.

Historical clients, game data and surviving resources are studied separately to improve our understanding of the original game.

Research has helped recover information relating to:

- original gameplay behavior
- Unity client structure
- scene organization
- interface composition
- character and content relationships
- progression systems
- gameplay systems
- network behavior
- historical features
- differences between surviving versions of SiD

Historical artifacts are preserved as research evidence rather than treated as active game builds.

This distinction is important.

Recovered historical material helps answer questions about the original experience, while the active project focuses on reconstructing that experience into a stable playable environment.

# ✦ Reconstruction Philosophy

SiD Legacy follows a simple development principle:

> ### Investigate to implement — not simply to know everything.

Preservation research is driven by the needs of the playable game.

When a system requires reconstruction, the process generally involves:

**Observe**

↓

**Understand the important behavior**

↓

**Recover surviving evidence**

↓

**Reconstruct the system**

↓

**Test it in runtime**

↓

**Validate persistence and failure behavior**

↓

**Compare against surviving references**

↓

**Improve fidelity**

The objective is not to collect endless disconnected discoveries.

The objective is to turn recovered knowledge into a functioning game.

# ✦ Visual Identity

SiD Legacy is intended to remain visually recognizable as **SiD**.

The original game's artwork, interface and visual language serve as the primary reference during reconstruction.

The goal is not to transform SiD into a generic modern interface.

Instead, surviving visual elements are carefully reconstructed and adapted where necessary so that the game can function on modern displays while retaining its recognizable identity.

This includes work on:

- original interface composition
- backgrounds
- UI frames
- buttons
- icons
- character presentation

- screen layout
- responsive behavior

Visual fidelity will continue to improve throughout development.
